# Fortune Cookie Wisdom for Developers

A make.fun entry (program/v1). Running `main.py` writes one original
fortune-cookie line for a software developer to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.

The fortune:

> Tonight a stranger will save your deploy: past you, in a comment you have scrolled past a hundred times.
